# Инструкции агента для проекта «ИИ СКАНЕР»

## Постоянная синхронизация с GitHub

Репозиторий проекта: https://github.com/DL4477/AI-SKANER-BL.git (`origin`). Основная ветка: `main`.

- Перед началом каждой задачи проверяй текущую ветку, `git status` и адрес `origin`, затем выполняй `git fetch origin`. Получай обновления текущей ветки из её upstream через fast-forward, если это не затрагивает незакоммиченные правки. Не переключай ветки автоматически ради синхронизации.
- После завершения задачи проверяй результат, создавай коммит с понятным описанием и отправляй изменения текущей ветки в `origin`. Для новой ветки настраивай upstream. Обычные коммиты и отправка изменений по задаче разрешены пользователем без дополнительного подтверждения, если он явно не попросил оставить работу локально.
- Включай в коммит только изменения выполненной задачи. Сохраняй существующие правки пользователя; не добавляй посторонние файлы, секреты, токены, пароли и `.env`.
- Если изменений нет, не создавай пустой коммит. Перед отправкой уже существующих локальных коммитов проверяй, что они относятся к разрешённой работе.
- Не используй force push, удаление истории или `reset --hard` для синхронизации. При расхождении истории, конфликтах или риске потери правок останови синхронизацию, сохрани работу и сообщи пользователю причину.
- После отправки проверяй, что локальная ветка и её ветка на GitHub указывают на один коммит. В итоговом ответе кратко сообщай статус синхронизации.
- Если GitHub недоступен или не хватает прав, явно сообщай, что изменения остаются локальными, и указывай причину. Не заявляй об успешной синхронизации без проверки.

Это правило действует при работе агента над задачами проекта; отдельную фоновую синхронизацию оно не запускает.
