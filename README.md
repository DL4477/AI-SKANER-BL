# ИИ СКАНЕР

Локальное Windows-приложение для агента чтения инженерных PDF-чертежей. Версия 0.4.0 добавляет подготовку PDF крупными фрагментами, извлечение текста и локальные RapidOCR/Tesseract перед существующим анализом Kimi. Поверхности, размеры и технические требования отображаются в интерфейсе и сохраняются в черновой JSON. Полнота геометрии и готовность к построению 3D требуют отдельной проверки. [Подготовка PDF и статус приёмки 0.4](docs/pdf-preparation-040.md).

## Что доступно

- Просмотр учебного эскиза втулки с четырьмя поверхностями.
- Выбор поверхности и подсветка её границы на эскизе.
- Карточки геометрии, местных и общих технических требований.
- Отдельная вкладка общих сведений о детали.
- Открытие локального PDF без отправки файла на сервер. Для загруженного PDF учебные результаты скрываются.
- Кнопка «Подготовить PDF»: локальное чтение всех листов без обращения к API, просмотр фрагментов, вариантов текста и расхождений, отмена и кэш текущего документа.
- Настройки Kimi K3 с хранением ключа в Windows Credential Manager, его заменой и удалением.
- Ручные проверки доступа к API, текстового ответа, изображения и JSON Schema; ошибки, время ответа, расход токенов и отмена ожидания.
- Действующая кнопка «Разобрать чертёж» сверху справа: анализ учебного эскиза или всех листов открытого PDF, остановка, карточки результата, вопросы и сохранение JSON.
- Проверка ответа по JSON Schema и контроль ссылок на общие требования и номера листов.
- Журнал текущего сеанса и изменение масштаба. PDF.js отображает страницы PDF внутри интерфейса с переключением страниц.

До запуска анализа учебные значения заданы вручную. После успешного ответа они заменяются результатом Kimi. Ключ сохраняется между запусками; открытый PDF, результаты анализа, проверок и журнал — только до закрытия окна. Сохраните нужный результат кнопкой «Сохранить JSON». Защищённые паролем PDF пока нужно открывать в другой программе. Шрифты и ресурсы PDF.js включены в сборку; внешние сервисы просмотра не используются.

Пробный анализ поддерживает PDF до 8 листов и 40 МБ. Для сложного чертежа предусмотрено до 15 минут, с получением ответа частями и отображением прошедшего времени. Все листы подготавливаются локально; изображения передаются в Kimi по нажатию кнопки. Запрос платный. Учебный эскиз можно анализировать без открытия PDF. [Как работает анализ и что нужно проверить](docs/drawing-analysis.md).

## Локальное приложение

После установки запускайте «ИИ СКАНЕР» через ярлык на рабочем столе или в меню «Пуск». Интерфейс, учебный пример и просмотрщик PDF встроены в исполняемый файл. Для запуска и просмотра PDF не нужны VS Code, сервер разработки или интернет. Проверки Kimi требуют интернета, API-ключа, а генерация — средств на счёте Kimi.

OCR поставляется в каталоге `ocr` рядом с приложением, включая Python runtime, модели ONNX и словари Tesseract. Самостоятельно устанавливать Python, OCR или VS Code пользователю не нужно. Подготовка работает на CPU без облачного OCR; файлы моделей при запуске не скачиваются.

Откройте «Модель и инструменты», вставьте API-ключ и сохраните его. Проверки подключения запускаются отдельными кнопками и используют только встроенные учебные данные. Кнопка «Разобрать чертёж» в рабочей области передаёт изображения открытого документа в Kimi. Сохранение ключа само по себе не вызывает API. В браузерном предпросмотре подключение отключено. [Устройство подключения и проверка](docs/model-connection.md).

На компьютере проекта приложение установлено в `%USERPROFILE%\Applications\ИИ СКАНЕР\ai-skaner.exe`. Ярлыки указывают на этот файл. Исходники и среда разработки находятся отдельно в папке проекта.

Установщик для текущего пользователя Windows находится после сборки в `src-tauri/target/release/bundle/nsis`. На новом компьютере путь по умолчанию — `%LOCALAPPDATA%\ИИ СКАНЕР`; его можно изменить при установке. Для удаления служит `uninstall.exe` в папке приложения. Требуется Microsoft Edge WebView2; на этом компьютере он уже установлен, а на другом компьютере установщик загрузит его при отсутствии.

## Запуск в VS Code

Откройте `AI-SKANER.code-workspace`. В меню «Терминал → Выполнить задачу» выберите «Приложение: запустить отдельным окном» для разработки или «Приложение: собрать установщик Windows» для самостоятельной версии. Остановите отдельно запущенную задачу «Интерфейс: запустить» перед запуском настольного режима разработки: обе используют порт 5173.

Предпросмотр в браузере доступен через «Интерфейс: запустить». Задача «Интерфейс: проверить сборку» проверяет TypeScript и собирает интерфейс.

На новом компьютере нужны Node.js 22.12+ или 24 LTS и pnpm. Сначала выполните задачу «Интерфейс: установить зависимости». В среде Codex вспомогательный скрипт также умеет использовать уже установленный комплект Node.js и pnpm. Он не устанавливает программы автоматически.

Для сборки настольной версии также нужны Rust с MSVC toolchain, Microsoft C++ Build Tools с компонентом «Разработка классических приложений на C++» и WebView2. [Официальные требования Tauri](https://v2.tauri.app/start/prerequisites/). Эти средства нужны разработчику, а не пользователю установленного приложения. Версии зависимостей закреплены в `pnpm-lock.yaml` и `src-tauri/Cargo.lock`.

Перед первой сборкой 0.4 разработчик также запускает `tools/ocr/build.ps1 -Python <путь к Python 3.12 x64>`. Скрипт создаёт изолированное окружение, устанавливает закреплённые зависимости, проверяет SHA-256 моделей и собирает автономный OCR в `.local/ocr-dist`. Затем обычная команда сборки включает этот каталог в установщик. Изменения `tools/ocr/worker.py` требуют повторной упаковки OCR. На чистом checkout без собранного компонента установщик не собирается — неполная сборка не выпускается.

Обычный запуск из терминала:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

```powershell
pnpm build
pnpm desktop:dev
pnpm desktop:build
```

## Структура проекта

`src/ui/src` содержит интерфейс и его демонстрационные данные; `src/ui/src/model` — настройки и состояния подключения; `src/ui/public/demo-bushing.svg` — учебный эскиз; `src-tauri/src/ai` — защищённое хранение ключа, клиент Kimi и проверки; `src-tauri` — также настольное окно, значок и конфигурацию установщика; `tools/ui.ps1` — запуск задач в Windows. Исходный код не содержит рабочих ключей API, пользовательских PDF или результатов их обработки.

[План приложения](docs/application-design-plan.md) описывает дальнейшие этапы. [Решения проекта](docs/decisions.md) фиксируют принятые границы работы. [Первый интерфейс](docs/interface-v01.md) описывает этот шаг и сценарии проверки.
