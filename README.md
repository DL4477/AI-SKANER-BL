# ИИ СКАНЕР

Приложение для будущего агента чтения инженерных PDF-чертежей. Текущий этап — первый интерфейс на React и TypeScript. Ядро агента, распознавание и экспорт JSON будут добавляться отдельно.

## Что доступно

- Просмотр учебного эскиза втулки с четырьмя поверхностями.
- Выбор поверхности и подсветка её границы на эскизе.
- Карточки геометрии, местных и общих технических требований.
- Отдельная вкладка общих сведений о детали.
- Открытие локального PDF без отправки файла на сервер. Для загруженного PDF учебные результаты скрываются.
- Макет настроек модели, журнал текущего сеанса и изменение масштаба. PDF.js отображает страницы PDF внутри интерфейса с переключением страниц.

Учебные значения созданы вручную. Настройки сохраняются только в памяти страницы. Кнопки разбора и экспорта отключены до реализации соответствующих функций. Защищённые паролем PDF пока нужно открывать отдельно. Шрифты и ресурсы PDF.js копируются из установленного пакета при запуске и сборке; внешние сервисы просмотра не используются.

## Запуск в VS Code

Откройте `AI-SKANER.code-workspace`. В меню «Терминал → Выполнить задачу» выберите «Интерфейс: запустить» и перейдите по адресу из терминала. Задача «Интерфейс: проверить сборку» проверяет TypeScript и собирает интерфейс.

На новом компьютере нужны Node.js 22.12+ или 24 LTS и pnpm. Сначала выполните задачу «Интерфейс: установить зависимости». В среде Codex вспомогательный скрипт также умеет использовать уже установленный комплект Node.js и pnpm. Он не устанавливает программы автоматически.

Обычный запуск из терминала:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

```powershell
pnpm build
```

## Структура проекта

`src/ui/src` содержит интерфейс и его демонстрационные данные; `src/ui/public/demo-bushing.svg` — учебный эскиз; `tools/ui.ps1` — запуск задач в Windows. Исходный код не содержит ключей API, пользовательских PDF или результатов их обработки.
